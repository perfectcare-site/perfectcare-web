김해 대동산단 작업사례 모바일 사진 잘림 수정

1. ZIP 압축을 풉니다.
2. GitHub의 perfectcare-web 저장소로 들어갑니다.
3. Add file → Upload files를 누릅니다.
4. 압축을 푼 폴더 안의 works 폴더를 업로드합니다.
5. 기존 works/gimhae-daedong-regular-cleaning/index.html 파일이 수정됩니다.
6. Commit changes를 누릅니다.
7. 1~3분 뒤 모바일에서 페이지를 새로고침합니다.

수정 내용
- 본문 사진의 1:1 강제 비율 제거
- 대표 사진의 16:9 강제 비율 제거
- 사진 원본 비율 그대로 표시
- 모바일에서도 width 100%, height auto로 전체 사진 표시
