김해 대동산단 정기청소 작업사례 업로드 방법

1. 이 ZIP 파일의 압축을 풉니다.
2. GitHub의 perfectcare-web 저장소로 이동합니다.
3. Add file → Upload files를 누릅니다.
4. 압축을 푼 폴더 안의 다음 항목을 GitHub 업로드 화면으로 끌어다 놓습니다.
   - index.html
   - sitemap.xml
   - works 폴더
   - assets 폴더
5. 같은 이름의 기존 파일은 수정 파일로 처리됩니다.
6. Commit changes를 누릅니다.
7. 1~3분 뒤 https://perfectcareclean.com/works/gimhae-daedong-regular-cleaning/ 주소를 확인합니다.
8. Ctrl + F5로 새로고침합니다.
