작업사례 목록 페이지 복구

이 파일은 /works/ 에 들어가면 마지막 글 하나만 보이는 문제를 수정합니다.

업로드 방법
1. ZIP 압축을 풉니다.
2. GitHub perfectcare-web 첫 화면에서 Add file → Upload files
3. 압축을 푼 works 폴더를 그대로 업로드
4. Commit changes
5. 1~3분 뒤 https://perfectcareclean.com/works/ 확인

정상 화면
- 정기청소 / 대청소 / 에어컨청소 카테고리 3개가 보임
- 최근 작업사례 4개가 카드로 보임
- 각 카드를 클릭하면 해당 상세 글로 이동
