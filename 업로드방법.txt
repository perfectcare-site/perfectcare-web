양산 증산 병원 바닥박리 청소 홈페이지 업로드 방법

1. ZIP 파일 압축을 풉니다.
2. GitHub에서 perfectcare-web 저장소로 들어갑니다.
3. Add file → Upload files를 누릅니다.
4. 압축을 푼 폴더 안의 아래 항목을 모두 업로드 화면으로 끌어다 놓습니다.
   - index.html
   - sitemap.xml
   - works 폴더
   - assets 폴더
5. Commit changes를 누릅니다.
6. GitHub Pages 반영까지 1~3분 정도 기다립니다.
7. 아래 주소를 열어 확인합니다.
   https://perfectcareclean.com/works/yangsan-jeungsan-hospital-floor-stripping/
8. 모바일에서도 사진이 잘리지 않고 전체가 보이는지 확인합니다.
9. 네이버 서치어드바이저 URL 검사에서 새 페이지 주소를 검사한 뒤 수집 요청합니다.
